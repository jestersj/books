# База книг

Личная база заметок о прочитанных книгах в формате Markdown/Obsidian.

## Структура

- `Books/` — карточки книг;
- `Templates/` — шаблоны карточек;
- `Справочники/` — правила заполнения;
- `Главная.md` — главная страница базы.

Для анализа базы ИИ можно передать ссылку на этот репозиторий или на отдельные Markdown-файлы.
