# Библиотека

## Сейчас читаю

```dataview
TABLE WITHOUT ID
  file.link AS "Книга",
  author AS "Автор",
  genre AS "Жанр",
  format AS "Формат"
FROM "Books"
WHERE status = "reading"
SORT file.name ASC
```

## Прочитано

```dataview
TABLE WITHOUT ID
  file.link AS "Книга",
  author AS "Автор",
  rating AS "Оценка",
  dateformat(finished, "yyyy-MM") AS "Прочитано",
  genre AS "Жанр",
  format AS "Формат"
FROM "Books"
WHERE status = "read"
SORT finished DESC
```

## Лучшие книги

```dataview
TABLE WITHOUT ID
  file.link AS "Книга",
  author AS "Автор",
  rating AS "Оценка",
  genre AS "Жанр"
FROM "Books"
WHERE status = "read" AND rating >= 8
SORT rating DESC
```

## Без заполненной оценки

```dataview
LIST
FROM "Books"
WHERE status = "read" AND !rating
SORT file.name ASC
```
