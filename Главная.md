# Библиотека

## Лучшие книги

```dataview
TABLE WITHOUT ID
  file.link AS "Книга",
  author AS "Автор",
  rating AS "Оценка",
  genre AS "Жанр"
FROM "Books"
WHERE finished AND rating >= 8
SORT rating DESC
```

## Прочитано

```dataview
TABLE WITHOUT ID
  file.link AS "Книга",
  author AS "Автор",
  rating AS "Оценка",
  dateformat(finished, "yyyy-MM") AS "Прочитано",
  genre AS "Жанр"
FROM "Books"
WHERE finished
SORT finished DESC
```
